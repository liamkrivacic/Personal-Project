UNSW SumoBots is a competition where autonomous robots try to push each other out of a ring.
Once the match starts there's no human input, so the robot has to find the opponent, push it,
and stay inside the white boundary line by itself. I entered the advanced stream, which allows
more capable hardware, and won it in August 2024. The chassis went through 16 revisions before
the final version.

<Callout title="Competition result">
**Advanced stream winner**, UNSW SumoBots, August 2024. The robot ran fully autonomously, with no
remote control and no human input after the start signal.
</Callout>

## Mechanical design

I designed the chassis in Fusion 360 over 16 revisions. The early ones were about getting the
basic layout right: a low wedge with enough floor area to mount three ultrasonic sensors at the
front without them sticking out past the robot's outline. Anything that sticks out can get
caught by the opponent and snapped off during a match, and a lot of the revisions were me
learning that and moving parts back inside the body.

The main manufacturing decisions were:
- **Laser-cut acrylic** for the five flat structural panels (floor, two sides, back and roof),
  with tab-and-slot joints so the panels hold themselves in place during assembly.
- **3D printing** for the front sensor bracket, which had to hold three ultrasonic sensors at
  specific outward angles. That shape was too complex to make from flat sheet.
- **Low centre of mass.** The battery and Arduino sit as low as possible so the robot doesn't tip
  backwards when pushing hard.
- **Wedge profile.** The angled front makes it harder for the opponent to get underneath, which
  was the most common way robots lost in earlier rounds.

## Electronics and sensors

The robot has three ultrasonic distance sensors covering the front, front-right and front-left.
With that spread it can see an opponent off to one side and turn toward it, instead of only
driving straight ahead. That turning behaviour won most of the matches.

IR line sensors underneath watch for the white boundary. When one triggers, the robot stops what
it's doing, reverses and turns away from the edge, then goes back to searching.

Each sensor has its own trigger/echo pin pair (A, B, C), so all three are read in a single pass
of the main loop. A slow sensor loop means the robot reacts late, which loses matches.

## Control logic

The firmware has to balance staying inside the ring with going after the opponent. I hard-coded
the priority order into the main loop so the robot never has to decide which matters more:

1. Read the IR sensor. If the boundary line is detected, reverse then turn away from the
   edge before doing anything else.
2. Read all three ultrasonic sensors in sequence.
3. If the front sensor reads an opponent within range, drive forward.
4. If a side sensor reads an opponent, turn toward the stronger return.
5. If no opponent is detected, rotate slowly to search the arena.

The `DISTANCE_TRIGGER` constant (70 cm in the final firmware) was set by trial and error during
practice runs. Too low and the robot ignored opponents at the edge of its side sensors' range.
Too high and it started reacting to the arena walls. At 70 cm it reacted to opponents but not to
the room.

Each side's motors are driven separately with PWM, so the robot can turn gradually by running one
side forward and stopping the other instead of reversing to change direction. The competition
requires a 5-second delay at the start, which runs as a one-shot flag on the first loop pass so it
doesn't block the serial monitor I used for debugging.

## What I learned

The mechanical, electronics and firmware decisions all depended on each other. The chassis shape
decided where the sensors could go, the sensor positions decided how the firmware worked, and how
aggressive the firmware was decided whether the chassis survived a hit. Because of that I ended up
changing all three together across the revisions, rather than finishing one before moving to the
next.

## Source code

<CodeBlock title="V4.2.ino - final competition firmware">

```cpp
// Motor 1
#define in1 10
#define in2 11

// Motor 2
#define in3 5
#define in4 6

// Distance sensor A (front)
#define trigPinA 9
#define echoPinA 8

// Distance sensor B (front-right)
#define trigPinB 3
#define echoPinB 2

// Distance sensor C (front-left)
#define trigPinC 7
#define echoPinC 4

// IR line sensor
#define IR 12

#define TURN_SPEED 255
#define FORWARD_SPEED 255
#define DISTANCE_TRIGGER 70

long durationA, durationB, durationC;
int distanceA, distanceB, distanceC;
int in1Speed = TURN_SPEED;
int in2Speed = 0;
int in3Speed = 0;
int in4Speed = TURN_SPEED;
int alert;
int mode;
char command;
int wait = 0;

void setup() {
  pinMode(in1, OUTPUT); pinMode(in2, OUTPUT);
  pinMode(in3, OUTPUT); pinMode(in4, OUTPUT);
  pinMode(trigPinA, OUTPUT); pinMode(echoPinA, INPUT);
  pinMode(trigPinB, OUTPUT); pinMode(echoPinB, INPUT);
  pinMode(trigPinC, OUTPUT); pinMode(echoPinC, INPUT);
  pinMode(IR, INPUT);
  Serial.begin(9600);
}

void loop() {
  // 5-second start delay (one-shot)
  if (wait == 0) {
    delay(5000);
    wait = 1;
  }

  // Read ultrasonic sensors
  digitalWrite(trigPinA, LOW); delayMicroseconds(2);
  digitalWrite(trigPinA, HIGH); delayMicroseconds(10); digitalWrite(trigPinA, LOW);
  durationA = pulseIn(echoPinA, HIGH);
  distanceA = durationA * 0.34 / 20;

  digitalWrite(trigPinB, LOW); delayMicroseconds(2);
  digitalWrite(trigPinB, HIGH); delayMicroseconds(10); digitalWrite(trigPinB, LOW);
  durationB = pulseIn(echoPinB, HIGH);
  distanceB = durationB * 0.34 / 20;

  digitalWrite(trigPinC, LOW); delayMicroseconds(2);
  digitalWrite(trigPinC, HIGH); delayMicroseconds(10); digitalWrite(trigPinC, LOW);
  durationC = pulseIn(echoPinC, HIGH);
  distanceC = durationC * 0.34 / 20;

  alert = digitalRead(IR);

  // IR line detection: reverse then turn (highest priority)
  if (alert == HIGH) {
    analogWrite(in1, 0); analogWrite(in2, FORWARD_SPEED);
    analogWrite(in3, 0); analogWrite(in4, FORWARD_SPEED);
    delay(1200);
    in3Speed = 0; in4Speed = TURN_SPEED;
    in1Speed = TURN_SPEED; in2Speed = 0;
    mode = 5;
  }
  // No opponent in range: slow rotation search
  else if (distanceA > DISTANCE_TRIGGER && distanceB > DISTANCE_TRIGGER && distanceC > DISTANCE_TRIGGER) {
    delayMicroseconds(500);
    mode = 1;
  }
  // Front sensor: drive forward
  else if (distanceA <= DISTANCE_TRIGGER) {
    delay(distanceA * 0.45);
    in1Speed = FORWARD_SPEED; in2Speed = 0;
    in3Speed = FORWARD_SPEED; in4Speed = 0;
    mode = 2;
  }
  // Right sensor: turn right
  else if (distanceB <= DISTANCE_TRIGGER) {
    in1Speed = 0; in2Speed = TURN_SPEED;
    in3Speed = TURN_SPEED; in4Speed = 0;
    mode = 3;
  }
  // Left sensor: turn left
  else if (distanceC <= DISTANCE_TRIGGER) {
    in1Speed = TURN_SPEED; in2Speed = 0;
    in3Speed = 0; in4Speed = TURN_SPEED;
    mode = 4;
  }

  analogWrite(in1, in1Speed); analogWrite(in2, in2Speed);
  analogWrite(in3, in3Speed); analogWrite(in4, in4Speed);

  // Serial debug interface
  if (Serial.available() > 0) {
    command = Serial.read();
    if (command == 'm') Serial.println(mode);
    else if (command == 'r') {
      Serial.println(in3Speed);
      Serial.println(in4Speed);
    }
    else if (command == 'd') {
      digitalWrite(trigPinA, LOW); delayMicroseconds(2);
      digitalWrite(trigPinA, HIGH); delayMicroseconds(10); digitalWrite(trigPinA, LOW);
      durationA = pulseIn(echoPinA, HIGH);
      distanceA = durationA * 0.34 / 20;
      Serial.print("DistanceA: "); Serial.println(distanceA);
    }
  }
}
```
